How these pages are made

  • Each page is a capture of openline-revisions-hub at 1440px wide, with its scripts removed. Text, images and layout are real; menus, tabs and forms don't respond.
  • The animations are the live option code from the review boards — edit an option there and it changes here too.
  • The blog hero is one slot with two boards drawn for it (Hero and Video cover). The panel flips between them.
  • Network, Security, AdBlocking, Unlimited and Blog carry a proposed page identity. It recolours that page and its animations, and can be switched off in the page's panel.
  • Every product page has a separate redesign. Use each page's Redesign link, the Current / Redesign switch, or the page dropdown to compare. The originals, chosen animations and page identities stay available.
  • Recolouring moves every accent around the colour wheel. Photos, raster logos and the Lottie hero art can't be recoloured.
