Which code is which?

Your purchase unlocks the profile. The profile is what your phone installs.

Openline purchase code

Found in your order email and dashboard. Enter it at /start to create your eSIM profile. It is not an installation code for your phone.

GAZE19-MULCH29-NYMPH13

eSIM activation code

Issued with your eSIM profile for manual setup, together with its SM-DP+ address. Enter those details in your phone’s eSIM settings, or scan the profile’s QR code instead.

Older wording: the purchase code was previously called an “activation code”. The order code and the eSIM’s manual activation code are not interchangeable.

To gift an unused purchase code, unlock it for transfer at /start. The purchase owner still receives an email to validate the purchase. Confirming activation starts your plan and ends gifting, so wait if your trip is later.
